# OIBSIP

#TASK 1-Number guessing game

DESCRIPTION:
This is a simple and interactive Number Guessing Game developed using the Java programming language. The program generates a random number between 1 and 100, and the user has to guess the correct number within a limited number of attempts.The game provides hints after each guess, indicating whether the entered number is too high or too low. It also includes a scoring system, making the game more engaging and challenging for the user.

FEATURES:
Random number generation
Limited attempts
Hints (Too High / Too Low)
Score system
Play again option

TECHNOLOGIES USED:
Java
VS Code / IntelliJ IDEA

#TASK 2-ATM Interface

DESCRIPTION:
The ATM Interface is a console-based Java application that simulates the basic functionalities of an Automated Teller Machine (ATM). This project allows users to perform banking operations such as checking account balance, depositing money, withdrawing money, and viewing transaction history.The application also includes a PIN authentication system to ensure basic security, making it more realistic and user-friendly.

FEATURES:
Secure PIN authentication
Check account balance
Deposit money
Withdraw money with validation
View transaction history
Input validation for safe transactions
Continuous menu-driven interface

TECHNOLOGIES USED:
Java (Core Java)
VS Code / IntelliJ IDEA
