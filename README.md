# OIBSIP

TASK 1:

This is a simple and interactive Number Guessing Game developed using the Java programming language. The program generates a random number between 1 and 100, and the user has to guess the correct number within a limited number of attempts.The game provides hints after each guess, indicating whether the entered number is too high or too low. It also includes a scoring system, making the game more engaging and challenging for the user.
